# Account logo sources

Retrieved 2026-10-29 from the companies’ public websites. Brand artwork is used unchanged to identify an account provider; it does not indicate a partnership or a live connection. Images are embedded in `public/brand-logos.js`, so displaying an account never sends its name or financial data to a logo service. Unrecognized names retain their category icon.
